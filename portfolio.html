Giới thiệu

Xin chào! Tôi là Alex Chen, lập trình viên front-end với 3 năm kinh nghiệm xây dựng giao diện web bằng HTML, CSS và JavaScript. Tôi thích tạo ra những trang web vừa đẹp vừa dễ tiếp cận cho mọi người dùng.

Kỹ năng

  • HTML5 & CSS3 ngữ nghĩa (semantic)
  • JavaScript (ES6+)
  • Thiết kế responsive và kiểm thử khả năng truy cập (accessibility)

Dự án nổi bật

Ứng dụng dự báo thời tiết

Ứng dụng web hiển thị dự báo thời tiết theo thời gian thực, sử dụng API công khai và biểu đồ tương tác để người dùng dễ theo dõi.

Tài liệu Fetch API tôi đã dùng để xây dựng dự án (MDN)

Trang tìm công thức nấu ăn

Công cụ tìm kiếm công thức nấu ăn theo nguyên liệu có sẵn, giúp người dùng giảm lãng phí thực phẩm.
